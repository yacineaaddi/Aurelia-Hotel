## ⚙️ Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/yacineaaddi/Aurelia-Hotel.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Aurelia-Hotel
   cd admin
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the application:

   ```bash
   npm run dev
   ```
